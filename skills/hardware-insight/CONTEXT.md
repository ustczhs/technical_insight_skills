# hardware-insight

结构化智能硬件调研的领域术语。包公约见仓库根 [CONTEXT.md](../../CONTEXT.md)。

## Language

**分析师立场**:
调研写作所站的身份。推荐默认是「TCL 技术规划师」，此为第一方。另选「中立第三方」则没有我方主体。
_Avoid_: 无默认组织, Lazy 默认中立第三方

**我方主体**:
建议与判断所服务的组织。立场为「TCL 技术规划师」时，主体是 TCL。中立第三方没有我方主体。
_Avoid_: 分析师立场, 假设进入者

**五看三定**:
一份战略判断的结构：先做五看，再做三定。五看提供事实与判断，三定把判断收成我方要握住的东西、要达成的结果、以及路径。仅当存在我方主体时成立；中立第三方不适用。
_Avoid_: SWOT, 决策摘要

**看行业**:
行业趋势、政策走向与技术演进。依据是行业报告、政策文件与新闻。
_Avoid_: 看竞争, 技术分析（实现原理）

**看客户**:
客户需求变化、痛点与新兴场景。依据是用户调研、社区讨论与产品评价。
_Avoid_: 看竞争, 销量口碑（竞品表现）

**看竞争**:
竞手动态、策略差异与市场份额。依据是竞品官网、财报与新闻。
_Avoid_: 看行业, 看客户

**看自己**:
自身优劣势、资源禀赋与能力边界。依据是内部资料与公开信息。
_Avoid_: 竞品优劣势, SWOT 的机会/威胁

**看机会**:
破局点、可行性与优先级。它综合前四看，不单独另找一套事实。
_Avoid_: 商业机会（未强制综合前四看时）, 看行业

**三定**:
定控制点、定目标、定策略这三项，且按此顺序。控制点未定，目标与策略不成立。
_Avoid_: 定战略 / 定目标 / 定策略, 方案选项表

**定控制点**:
我方必须握住、且对手难以在同样条件下复制的差异化卡位或能力。
_Avoid_: 目标, 优势清单

**定目标**:
可检验的结果，含时间、规模或产品里程碑中的至少一项。
_Avoid_: 愿景, 控制点

**定策略**:
在已定控制点之下、通向已定目标的路径。
_Avoid_: SWOT 的 2×2 策略, 建议方向（未绑定控制点与目标时）
