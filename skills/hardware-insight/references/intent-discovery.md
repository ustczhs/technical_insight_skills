# 意图发现与问询（Step 0–2）

内嵌 brainstorming（语境扫描、一次一题、分段确认）与 grilling（决策树压测、事实自查、共识前不执行）思想。**不 invoke** 外部 skill。

**读取边界**

- Step 1–8 **只读** `调研基调.md`
- `调研意图.md` 供人回顾与 Step 0 续跑；后续步骤**不得依赖**

---

## A. 交互纪律（选择题）

对用户的每一道决策题（含 Step 0/1/2/8 闸门、grill、Lazy 第一题）遵守：

1. **一次一题**：等用户答完再继续；同一条消息、同一次 `AskQuestion` **只含一道题**（禁止 0c/Step 8 一张表连发多字段）。
2. **形态**：必须是选择题。题干标明 **（单选）** 或 **（多选）**。
3. **推荐**：每题必须给出推荐项 + 一句理由；在选项上标注「（推荐）」。旧规则「开放决策题只问不推荐」**作废**。
4. **末项手动输入**：选项的**最后一项**固定为「其他（请补充）」。用户选此项或输入自由文本时，按文本写入基调，不强迫套进前几项。
5. **呈现**：优先 `AskQuestion`（`options` 最后一项 `id: other`，label `其他（请补充）`；多选设 `allow_multiple: true`）。无该工具时用正文列表，格式见下。
6. **事实 vs 决策**
   - **事实**（产品是否存在、已有 research、公开规格、在售）：agent 自查，**不问用户**。
   - **决策**（T0 边界、深度、必证项、分析师立场、我方主体、明确不做、成功标准、报告取向）：逐步确认下**必须问**并等待；Lazy 下用推荐值，不问。
7. **共识闸门**（逐步确认）：`Step 0 状态` 为 **已确认** 前，**不得进入 Step 1**。
8. **交错写入**：问询中随时更新 `调研意图.md` + `调研基调.md` 草稿。
9. **题量上限**（逐步确认）
   - Step 0 full grill：最多 8 轮
   - Step 0 简流程：1–3 轮（不含 Lazy 第一题、不含 0c 参数题）
   - Step 1 / Step 2 轻量 grill：各最多 3 轮
   - 0c 参数：每字段一题，不得把整张表合成一轮

**正文选择题模板**

```
（单选）<问题>？**推荐：<项>**——<一句理由>。

- A. …
- B. …（推荐）
- C. 其他（请补充）
```

多选把题干改成（多选），推荐可多项。

## Lazy 模式

**时机**：项目闸门之后、Step 0 澄清题之前。已有 `Step 0 状态：已确认` 的续跑 **不问** Lazy。

**第一题**（单选），**推荐：关**：

- 关 Lazy，逐步确认（推荐）——避免随口课题被写成整套报告
- 开 Lazy，用推荐值连跑 Step 0–8
- 其他（请补充）

用户首句已明示「lazy / 全自动 / 不用问我」→ 视为已选开，不再问第一题。

**默认关。** 只有显式选开（或首句等价）才进入 Lazy。

**开启后**

1. 仍做 0a 语境扫描与公开检索；**跳过** 0b/0c/0d、Step 1/2/8 的等人确认。
2. 用大模型推荐填满 `调研基调.md`（议题、决策问题、目的/深度/范围/读者/扩展包/必证项、分层初稿）。每条推荐值在 `调研意图.md` 记「Lazy 采用：…」。
3. **分析师立场**固定为「中立第三方」；**我方主体**为「不适用」。标注 `Lazy 默认，非逐步确认`。
4. **交互模式**：`Lazy`。`Step 0 状态`：直接 `已确认`（确认时间 = 启用 Lazy 之日）。
5. Step 8 不问：`报告取向` = 决策导向；`生成信息图` = 否（style/aspect 留空）。
6. 自勾进度检查点 Step 0–8 对应项；连跑至报告 MD。信息图按「跳过」不生成。
7. 中立建议主语为行业/品类。

**中途改开**：用户说「改成 Lazy / 全自动」→ 未决闸门改用推荐值，从当前步骤连跑到 Step 8。

## B. 清晰度分流（agent 启发式）

无硬 checklist；**仅逐步确认**时判断 full grill 或简流程。Lazy 不做 grill 轮次。

### 模糊信号（倾向 full grill，≤8 轮）

- 缺**决策赌注**：说不清调研结束后要做什么决定
- **调研议题**一句说不清，或同时含多个未拆解子课题
- **范围过大**（如「全球所有 XX 硬件」）且未说明裁剪方式
- **我方主体**不明或未确认（第一方模式下）
- **分析师立场**未确认（逐步确认无默认；须用户自填或选中立）
- 仅有品类/赛道，无具体对标或决策命题
- 用户输入与已有 `$PROJECTS_ROOT/<project_slug>/research/` 产出明显冲突且未澄清

### 清晰信号（倾向简流程，1–3 轮）

- 有明确**决策命题**（如「X 能否用于 Y」「是否立项 Z」）
- 产品/品类/对标可识别
- 读者或调研目的已隐含或可快速确认
- 可参考已确认项目的 `调研基调.md` 结构（议题 + 核心决策问题 + 分层）

### 模糊输入专用：调研策略对比（一次，选择题）

full grill 中段议题成形时，**（单选）** 给出 2–3 种策略 + 推荐 + 末项「其他」：

| 策略 | 适用 | 代价 |
|------|------|------|
| **广度优先** | 品类扫描、机会探索 | T0 较浅，T2 较多 |
| **T0 深拆** | 已有明确对标，需硬证据 | 耗时，范围宜收窄 |
| **假设驱动** | 已有 3–5 条核心决策问题 | 模板与竞品列表强裁剪 |

## C. 问题库

全部按 §A 做成选择题（推荐 + 末项其他）。下列为题干与选项素材，一次只问一题。

### C.1 决策题（须带推荐）

按需选用：

1. **决策赌注**（单选）：立项评估 / 技术选型 / 竞品对标 / 融资材料 / 其他（请补充）。推荐随用户首句推断（如「选路线」→ 技术选型）。
2. **成功标准**（单选）：摸清现状与路线即可 / 必须给出可执行推荐 / 必须拿到指定 A 级证据 / 其他（请补充）。
3. **失败标准**（单选）：否定结论（不建议做）仍算调研成功 / 算失败须重做范围 / 其他（请补充）。推荐：仍算成功。
4. **时间敏感**（单选）：无硬 deadline / 有（请在其他项写日期） / 其他（请补充）。
5. **证据底线**（单选或必证项多选）：无强制拆机 / 关键规格须双源 / 其他（请补充）。
6. **明确不做**（多选）：BOM 拆解 / 供应链询价 / 法务认证结论 / 无额外排除 / 其他（请补充）。

### C.2 假设压测（grill）

形成初步假设后，用选择题挑战（仍一次一题、带推荐、末项其他）：

- T0 名单是否选对？是否上调/下调某竞品？
- **深度 × 范围 × 读者**是否匹配？
- 竞品分层是否与调研目的对齐？
- 「不做/降级」结论是否可接受？

### C.3 结构化采集（0c，一次一字段）

与 [SKILL.md Step 0](../SKILL.md) 表格字段一致；**每个字段单独一题**，带推荐：

| 字段 | 选项示例 |
|------|----------|
| 调研目的 | 立项评估 / 技术选型 / 竞品对标 / 融资材料 / 其他（请补充） |
| 深度 | 快速扫描（1–2 天）/ 标准调研 / 深度拆解 / 其他（请补充） |
| 范围 | 国内 / 全球 / 指定区域（请在其他项写明） / 其他（请补充） |
| 读者 | 管理层 / 产品 / 研发 / 投资人 / 其他（请补充） |
| 硬件扩展包 | 启用 / 不启用 / 其他（请补充） |
| 必证项 | （多选）无 / 拆机验证 / 认证查询 / 供应商询价 / 其他（请补充） |
| 分析师立场 | 中立第三方 / 第一方（请在其他项写身份） / 其他（请补充）。逐步确认无默认组织 |
| 我方主体 | 仅第一方；选项含「其他（请补充）」；skill 不预设组织名 |

竞品分层默认值（可让用户用选择题修正）：

- **T0**：直接对标且份额或技术领先
- **T1**：同价位替代
- **T2**：参考观察

## D. Step 0 四段流程

| 子步 | 动作 | 产出 |
|------|------|------|
| **0-lazy** | 见 §Lazy；若开则填基调并跳过下表 0b–0d 问询 | `交互模式：Lazy` |
| **0a 语境扫描** | 读 `$PROJECTS_ROOT/<project_slug>/research/`、检索公开事实 | `调研意图.md` 草稿 |
| **0b 澄清/压测** | 按清晰度 full(≤8) 或 lite(1–3)；选择题 | 交错更新双文件 |
| **0c 结构化采集** | 一次一题收集表格字段 | 更新 `调研基调.md` |
| **0d 定稿闸门** | （单选）确认基调 / 要改 / 其他 | `Step 0 状态：已确认` |

**跳过 Step 0 问询**：`调研基调.md` 已存在且 `Step 0 状态：已确认` → 直接从 `进度.md` 续跑。

## E. Step 1 轻量 grill（≤3 轮）

**触发**：模板生成后、进入 Step 2 前。**Lazy 跳过**，采用推荐裁剪。

**不做**：重复 Step 0 已确认的字段。

**典型问法**（一次一题，单选，含推荐与「其他」）：

1. **裁剪方案**：全 13 节分层深浅 / T2 只填必填节 / 其他（请补充）。
2. **MECE**：保持分节 / 合并指定两节（标题仍留） / 其他（请补充）。

确认后更新 `调研模板.md`，勾选 `Step 1 模板确认`。

---

## F. Step 2 轻量 grill（≤3 轮）

**触发**：竞品列表生成后、进入 Step 3 前。**Lazy 跳过**，采用推荐分层。

**典型问法**（单选 + 推荐 + 其他）：T0 覆盖、分层上调/下调、是否砍间接竞品。

确认后更新 `竞品列表.md`，勾选 `Step 2 竞品列表确认`。

---

## G. 续跑与重做

### 续跑（Step 0 未完成）

- 存在 `调研意图.md` + `调研基调.md`，且 `Step 0 状态：待确认`
- 读 `调研意图.md` 定位**最后未决分支**，从下一题续问（仍一次一题）
- **不重头** grill，除非用户明确要求

### 续跑（Step 0 已完成）

- `Step 0 状态：已确认` → 跳过 Step 0 问询与 Lazy 第一题，从 `进度.md` 当前步骤继续

### 重做 Step 0

- 用户说「重做 Step 0」→ 重新生成 `调研意图.md` + `调研基调.md`；**重新问 Lazy 第一题**（除非用户同时说保持 Lazy/逐步确认）

### 旧项目兼容

- 仅有 `调研基调.md`、无 `调研意图.md` 且 **已确认** → **不强制补写**
- 无 `交互模式` 字段的旧基调视为 `逐步确认`

---

## H. 产出自检（Step 0d 定稿前 / Lazy 落盘后）

1. `调研议题` 是否一句可复述？
2. `核心决策问题` 是否 3–5 条？
3. 基本参数表是否齐全？`交互模式` 是否已写？
4. **分析师立场**：逐步确认须用户填写（不得代填组织名）；Lazy 须为「中立第三方」并标注 Lazy 默认。
5. 若立场非「中立第三方」，`我方主体` 是否已确认？
6. 竞品分层是否有依据（可仍为「待 Step 2 细化」）？
7. 逐步确认：`Step 0 状态` 在闸门前为 `待确认`；Lazy：落盘即为 `已确认`。

`调研意图.md` 无固定章节要求；至少记录：输入清晰度判断、扫描摘要、已问已答摘要（Lazy 则记录采用的推荐值）。
