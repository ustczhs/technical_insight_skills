# 报告合成与分析师立场（hardware-insight Step 4–8）

## 分析师立场（Lazy 之前必问）

| 字段 | 要求 | 说明 |
|------|------|------|
| 分析师立场 | **必填**。在 Lazy 题之前问 | 推荐「TCL 技术规划师」。用户也可选「中立第三方」或其他身份。Lazy **不得**改写已确认立场 |
| 我方主体 | 第一方必填 | 「TCL 技术规划师」→ TCL，不再单问。中立 →「不适用」 |
| 模式判定 | 值为「中立第三方」→ 中立模式；**其他任意自述**→ 第一方模式 | 写入 `调研基调.md` 后，Step 4–8 只读该字段 |

### 身份与写作约束

读取 `调研基调.md` 的 `分析师立场`（及 `我方主体`）：

**第一方模式**（立场 ≠「中立第三方」）：

- **身份**：以用户填写的立场原文为准（如「某司 AI 硬件技术规划师」）；产出供该方路线决策与竞争情报使用
- **竞品**：用 **威胁 / 机会 / 可借鉴技术** 框架分析
- **建议方向**主语必须是**我方主体**，不得为竞品写落地路线图
- **时间差**：我方未量产 vs 竞品已预售/在售时，须写追赶策略与差异化窗口
- **禁止**：把竞品作为「优先落地平台」写入建议

**中立第三方模式**（立场 =「中立第三方」）：

- 可为行业写建议，须标注「中立分析」
- 建议主语可为行业/品类；不以「我方」为强制主语

### 反例（禁止出现在建议方向）

第一方模式下，竞品不得作为建议主语（不得写成「优先在竞品平台落地」之类）。

## Step 4–7 加深要求

### Step 4 竞品分析

- 每个 **T0** 至少 **5 条**可引用数据点（带 [A/B/C] 与时效）
- 对比表含列：**对我方主体影响**（威胁/机会/无关/待观察）
- 文首：`调研信息截止：YYYY-MM-DD`
- 边界：不写实现原理（留给 Step 5）

### Step 5 技术分析

- 至少 **1 张架构图**（mermaid 或 ASCII）
- **Build vs Buy vs Partner** 三栏对比（针对核心能力）
- 技术结论双源交叉；文首附截止日
- 边界：不写市场表现（已在 Step 4）

### Step 6 商业机会

- 含量化字段：价格、窗口期、市场规模引用（标注证据等级）
- **竞争响应时间表**（竞品动作 → 我方可选响应）
- 与 Step 4/5 交叉引用，不单列二手信息

### Step 7a 决策摘要

- **核心结论** 3–5 条，回应调研目的与**我方主体**
- **方案选项**表含优势/劣势/风险
- **路线图**：0–6 / 6–18 / 18–24 月里程碑与 gate
- **资源粗估**：人月量级或依赖团队（算法/硬件/合规）
- **明确不做**：边界清单
- **建议方向**仅对我方主体；竞品仅作情报参照

### Step 7b SWOT 分析

独立产出 `swot分析.md`；**执行顺序**：在 `决策摘要.md` 完成后撰写。主输入为 Step 4–6 + `调研基调.md`；可交叉核对 `决策摘要.md` 方案选项与建议，但**不得**把 SWOT 正文并入决策摘要。

**来源映射**

| 象限 | 主要源文件 | 典型章节 |
|------|-----------|----------|
| S（内部优势） | `技术分析.md` | §成熟度与优劣势（我方） |
| W（内部劣势） | `技术分析.md`、`商业机会.md` | 我方劣势、做了代价/必要性判断 |
| O（外部机会） | `商业机会.md`、`竞品分析.md` | §机会、窗口期、竞争含义·机会 |
| T（外部威胁） | `商业机会.md`、`竞品分析.md` | §威胁、竞争含义·威胁 |

**内容要求**

- 四象限各 **3–5** 条；每条含 `[A/B/C]` + 信息时效
- 综合来源至少覆盖 **3 个** Step 4–6 文件
- **S/W** 为内部能力/约束，主语为我方主体；**不得**写成竞品优劣势
- **O/T** 为外部环境，来自市场与竞争分析
- **2×2 策略矩阵**：SO / ST / WO / WT 各 ≥1 条可行动策略；可关联 `决策摘要.md` 方案编号（O1/O2…）或路线图 Gate；不得空泛口号

**审核闸门**

- [ ] 四象限各 ≥3 条，且每条有证据标注
- [ ] 来源覆盖 `竞品分析.md`、`技术分析.md`、`商业机会.md` 中至少 3 个
- [ ] S/W 内外分离正确；主语为我方主体
- [ ] 2×2 矩阵四条策略均可行动，且与决策摘要不矛盾
- [ ] 未将 SWOT 正文复制进 `决策摘要.md`

**Step 8 边界**：报告/信息图**不强制**引用 `swot分析.md`；Step 8 综合阅读清单**不包含**本文件。五看三定取向除外：该取向须读 `swot分析.md` 与 `五看三定.md`。

### Step 7c 五看三定

仅**第一方**产出 `五看三定.md`。**执行顺序**：`决策摘要.md` → `swot分析.md` → `五看三定.md`。中立模式不创建该文件，进度检查点标 [ Y ] 并注明「不适用」。

术语见 [CONTEXT.md](../CONTEXT.md)。八节标题固定，顺序不可调：

1. 看行业
2. 看客户
3. 看竞争
4. 看自己
5. 看机会
6. 定控制点
7. 定目标
8. 定策略

**来源与写法**

| 节 | 写法 |
|----|------|
| 看竞争 | 引用 `竞品分析.md` 的策略差异、份额与对我方含义。不复制竞品拆解全文 |
| 看自己 | 引用 `swot分析.md` 的 S/W。不重写 2×2 策略矩阵 |
| 看行业 | 行业趋势、政策走向、技术演进。无行业报告/政策/新闻则整节可为信息缺口 |
| 看客户 | 需求变化、痛点、新兴场景。无用户调研、社区讨论或产品评价则整节可为信息缺口 |
| 看机会 | 只综合前四看里**已经写实**的看。破局点须标明来自哪一看 |

**信息缺口**（看行业 / 看客户 / 看自己，允许整节）须同时写：

- 缺什么
- 用什么材料补（行业报告或政策文件、用户原声、内部资料）

禁止用竞品规格冒充这三节。看机会里靠缺口推出的破局点标「证据不足」，不得标为优先。定控制点若主要依赖看自己、而看自己是缺口，标「待内部资料印证」，不得写成已确认卡位。

**三定**

- 顺序固定：控制点 → 目标 → 策略。控制点未写出时，不写目标与策略
- 定控制点至少 1 条，并指回某一看
- 定目标可检验：时间、规模或产品里程碑至少一项
- 定策略引用已写的控制点与目标
- 不得与 `决策摘要.md` 的建议方向矛盾；矛盾时**改五看三定**，不回改决策摘要

**审核闸门**

- [ ] 第一方：八节标题齐全；中立：文件不存在且进度为不适用
- [ ] 看竞争、看自己是引用判断，不是竞品拆解或 SWOT 矩阵的复制
- [ ] 缺口节写明缺什么、用什么补
- [ ] 看机会的每条破局点标明来源看；证据不足的未标为优先
- [ ] 三定顺序正确，目标可检验，且与决策摘要建议方向不矛盾
- [ ] 未将五看三定正文复制进 `决策摘要.md`

## 报告章节标准（按取向）

**单一事实来源**：撰写 `output/报告-<取向>.md` 时，**必须**复制项目根目录骨架模板章节结构：

| 取向 | 骨架模板 |
|------|----------|
| 决策导向 | [`templates/report/报告-决策导向.md`](../templates/report/报告-决策导向.md) |
| 科普导向 | [`templates/report/报告-科普导向.md`](../templates/report/报告-科普导向.md) |
| 投资人导向 | [`templates/report/报告-投资人导向.md`](../templates/report/报告-投资人导向.md) |
| 五看三定（仅第一方） | [`templates/report/报告-五看三定.md`](../templates/report/报告-五看三定.md) |

使用说明与质量 Rubric 见 [`templates/report/README.md`](../templates/report/README.md)。

**禁止**在报告中嵌入 `![...](infographics/...)`。格局/方案/技术/市场对比用 **Markdown 表格 + mermaid** 替代。

### 决策导向（顶级技术规划师对内汇报）

遵循 `templates/report/报告-决策导向.md` 全部章节（9 节 + 附录），核心要求：

1. **执行摘要**（≤1 页）：结论 + **我方建议** + 3–5 个关键数字（带证据等级）
2. **竞争态势与对我方含义**（综合 T0/T1，分析而非表格复述）
3. **技术路线与架构选择**（引用 Step 5，含推荐路径与弃选理由）
4. **集成方案对比**（来自决策摘要方案选项表）
5. **商业窗口**（量化 + 必要性判断）
6. **产品定义与体验边界**（做/不做/命名规范）
7. **路线图**（0–6 / 6–18 / 18–24 月，依赖与 gate）
8. **风险登记册**（概率 × 影响 × 缓解措施）
9. **待证事项**（聚合所有调研 §13）
10. **证据附录**（信息截止日、来源分级说明）

`output/大纲-<取向>.md`：每节 1–2 句要点，**禁止**仅含图片链接的空壳大纲；**禁止**引用信息图路径。

### 科普导向

遵循 `templates/report/报告-科普导向.md`，在决策骨架基础上**增删加权**：

- **增**：产品解构、技术原理阐释、常见误解澄清
- **压缩**：路线图与资源粗估
- **保留专节**：「对我方主体的含义」（不可省略）

### 投资人导向

遵循 `templates/report/报告-投资人导向.md`，**市场先行**叙事：

- 市场机会与规模（TAM/SAM、窗口期）
- 竞争格局与定位空白
- 技术与产品壁垒（可防御性语言）
- 商业模式与单位经济
- 风险与回报平衡、尽调清单

### 五看三定（仅第一方）

遵循 `templates/report/报告-五看三定.md`。撰写前在综合阅读清单之外**必须**再读 `五看三定.md` 与 `swot分析.md`。八节标题与源文件一致，叙述展开，不得照抄源文件。中立模式不提供该取向。

多取向时：**先**完成共用 `决策摘要.md`，再派生各报告；结论不得矛盾。五看三定报告还不得与 `五看三定.md` 的三定矛盾。

## Step 8 质量闸门（完成前自检）

未全部勾选则**不得**将 `进度.md` Step 8 标为已完成：

### 报告

- [ ] 遵循对应取向骨架模板（`templates/report/报告-<取向>.md`）的全部章节
- [ ] 每个主章节 ≥2 处交叉引用（来自不同源文件）
- [ ] 至少引用全部 **T0** 调研文件各 1 次
- [ ] 执行摘要含 ≥3 个带 [A/B/C] 或 `信息时效` 的具体事实
- [ ] 存在「对我方主体」相关论述；建议不以竞品为主语（中立模式除外）
- [ ] 大纲每节有实质要点（非空壳）
- [ ] 报告非 `决策摘要.md` 的缩写复述（篇幅与深度明显大于摘要）
- [ ] **无** `![...](infographics/...)` 图片引用

### 五看三定取向（仅当取向包含它）

- [ ] 八节与 `templates/report/报告-五看三定.md` 一致
- [ ] 已阅读 `五看三定.md`；看竞争、看自己不是竞品拆解或 SWOT 矩阵的复制
- [ ] 缺口节含「缺什么」与「用什么补」
- [ ] 三定与 `决策摘要.md` 建议方向、`五看三定.md` 均不矛盾
- [ ] 篇幅长于源文件 `五看三定.md`（展开叙述，不是照抄）

## 信息图质量闸门（可选附录）

仅当 Step 8 用户选择 **生成信息图** 时适用。信息图产出在 `output/infographics/`，**不嵌入**报告。

- [ ] 4 张图均有完整 `source.md` / `analysis.md` / `structured-content.md` / `data-manifest.md` / `prompts/infographic.md`（见 [infographic-source-map.md](infographic-source-map.md)）
- [ ] PNG 经 **agent 视觉自验** MustAppear 全部勾选，`verification: pass`（见 [infographic-rules.md](infographic-rules.md)）
- [ ] `output/infographics/_manifest.md` 校验通过（含 `render_backend` 为 imagegen 类、非 code）
- [ ] 4 张 PNG 使用 `infographic-{type}.png` 唯一命名
- [ ] `competitors` 语义覆盖 T0 文件数；无源中不存在的幻觉列/数字
- [ ] `tech` 图含 ≥3 处课题专名（非纯通用教程图）
- [ ] `analysis` 推荐侧含 ≥2 条代价/风险（来自决策摘要劣势/风险列）

用户选择 **跳过信息图** 时（含 Lazy 默认跳过），以上项不勾选，Step 8 仍可完成。
