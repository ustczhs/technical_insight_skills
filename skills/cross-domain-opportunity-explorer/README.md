# cross-domain-opportunity-explorer

**AI/Agent 跨域碰撞引擎**：尽量广地铺人群，用约束×形态深挖火花，检索要新，对人只给结论。

不是竞品深研、PRD 或选型。

细则：[SKILL.md](./SKILL.md)。术语：[CONTEXT.md](./CONTEXT.md)。包公约：[../../CONTEXT.md](../../CONTEXT.md)。

## 四条原则

| 原则 | 做法 |
|------|------|
| 覆盖尽量广 | 下限不是目标：Cell ≥40（目标 50–80），火花 ≥50（目标 ≥80） |
| 检索要新 | 现状事实优先最近 12 个月 |
| 挖掘要深、敢想 | 旅程×非常规透镜×跨域类比；允许 wild |
| 呈现要直接 | 对话只给 `SESSION_BRIEF`，表留在文件里 |

## 何时用

- 兴趣圈层 / 人生角色 / 状态场景的 AI×硬件机会扫描
- 已有场景直觉（如「上鱼瞬间双手被占」）要扩成地图
- `/cross-domain-opportunity-explorer`、跨域碰撞、机会火花

## 模式

| 模式 | 适用 | 量级 |
|------|------|------|
| `landscape` | 广筛撞火花 | Cell ≥40；火花目标 ≥80 |
| `deep-dive` | 单 Cell 深挖 | 1 Cell、3–5 场景；火花 ≥15 |

## 产出

写在 **`$PROJECTS_ROOT/<project_slug>/opportunities/`**，不要写仓库里的 `opportunities/`。

对人先读 `SESSION_BRIEF.md`。全树见 SKILL 收尾节。
