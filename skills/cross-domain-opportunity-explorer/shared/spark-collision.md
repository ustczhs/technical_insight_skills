# 火花碰撞引擎

本 skill 的**核心能力**：用 Agent 想象力做**深**的结构化跨域碰撞。覆盖要广，单条要深，禁止兴趣标签直接跳到「某某 AI 手环」。

碰撞前先读 [killed-patterns.md](killed-patterns.md)。

## 碰撞公式

```text
People Cell × 旅程节点 × Constraint Lens × 介入形态 → Opportunity Spark
```

加速器：

- **Seed Spark**：用户已给场景直觉时，先撞这一条并置顶，再扩池。
- **跨域类比**：A 域形态映射到 B 域约束；须标来源与 `类比匹配度`，仍为 `hypothesis`。

## 介入形态库

每个「透镜 × 节点」至少发散 **3** 路（必须含纯软件一路）。candidate 集合里头戴/眼戴 **≤50%**。

| 类别 | 形态示例 |
|------|----------|
| **头戴/眼戴** | 智能眼镜、运动相机、头灯集成、面罩 HUD |
| **耳戴/口戴** | 开放式耳机、骨传导、领夹麦 |
| **腕指/身戴** | 指环、手表、胸扣、腰带、智能服装 |
| **手持/随带** | 手机支架、云台、望远镜/测距仪、便携屏 |
| **附着/场景** | 竿夹、车夹、球杆夹、磁吸贴片、桌面 dock |
| **空间/固定** | KTV/球房/健身房/钓场设备、Beacon、投影 |
| **纯软件/Agent** | App、Concierge、社群 bot、内容模板 |
| **服务/人工** | 教练、导钓、陪练、代拍、空间会员 |

## 深挖要求（原则 3）

对每个入选 Cell：

1. 取 **2–3 个旅程节点**（不得只撞「进行」；至少再看准备 / 异常 / 分享 / 维持之一）。
2. 每节点 **2–4 个透镜**；至少 1 个非常规组合（如「长时间等待 × 社交展示」）。
3. 每「节点 × 透镜」≥3 形态。
4. 火花名必须能让外人听懂：**谁、在哪一秒、手/眼在干什么、装置做什么**。
5. **Unique Friction** 必填，禁止套话。
6. 每批至少 **5 条 wild**（大胆、暂不可证伪）；至少 **8 条跨域类比**（匹配度 med+ 才可进 candidate）。

landscape：**去重后 ≥50，目标 ≥80**。不够就扩 Cell / 非常规透镜 / 类比，不要复制粘贴凑数。

## 反模板（硬）

无效火花（须合并、重写或标 killed）：

- 无透镜的「×× AI 助手」
- Unique Friction 能换成另一个兴趣而不改字
- 最大杀伤问题仅为「App 够吗？」「手机够吗？」「手表够吗？」且无场景细节
- 全板同一杀伤句出现 ≥5 次（第 5 条起无效）
- 命中 [killed-patterns.md](killed-patterns.md) 且无新证据反驳

## 跨域类比

| 源域形态 | 可迁移约束 | 目标域示例 |
|----------|------------|------------|
| 滑雪/骑行头盔相机 | 双手占用 + 高速瞬间 | 路亚、摩托、单轮 |
| 健身视觉纠正 | 教学/陪练 | 台球、高尔夫、唱歌 |
| 婴儿监视器 | 长时间等待 + 异常 | 窝守、陪护 |
| 盘串/手表包浆记录 | 身份/仪式 | 文玩、键盘、Hi-Fi |
| KTV 混响/评分 | 社交 + 空间 | 家庭 K 歌、练歌房 |
| 开放耳 + 语音 Agent | 视线被占 + 免提 | 骑行、烹饪、工厂 |

每条类比写：`匹配度 high/med/low` + 一句话差异。**low 默认不进 candidate**。

## Spark Score（晋升）

五维各 0–2，满分 10。**candidate 须 ≥6 且至少两维为 2**。选 ≤8 条。

| 维 | 2 分 | 0 分 |
|----|------|------|
| 约束强度 | ≥2 透镜叠加且窗口/姿态具体 | 泛「不方便」 |
| 替代不足 | 写清现有方案仍失败的具体原因 | 「体验更好」 |
| AI 可触点 | 可感知信号 + 判断 + 行动闭环 | 泛聊天 |
| 差异化 | 批次内形态或场景不与前 3 名同构 | 又一个头戴 POV |
| 证据线索 | 有 ≤12 个月的 fact/voice/observation 指针 | 纯脑补 |

同分优先：Seed Spark 溯源、Pain+Itch 混合、非头戴形态。

## 与 Grill 的衔接

火花段不问人。杀伤写入「最大杀伤问题」（必须含场景）。晋升后走 [hypothesis-grill.md](hypothesis-grill.md)。
