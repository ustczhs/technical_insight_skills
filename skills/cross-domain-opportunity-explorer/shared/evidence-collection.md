# 证据采集与痛痒洞察

## 时效（原则 2）

| 来源年龄 | 用法 |
|----------|------|
| ≤12 个月 | 可支撑现状 fact / voice（仍须 URL+日期） |
| 12–24 个月 | 可用，标注「可能已变」 |
| >24 个月 | 仅趋势/背景，不得当现状产品或价格事实 |
| 无日期 | 最多 `observation`，confidence ≤ low |

检索查询须带年份或「最新」；同一主张优先新来源。厂商页不是用户 voice。

## 证据预算（防爆检索、保深度）

| 阶段 | 预算 | 用途 |
|------|------|------|
| landscape 薄采 | 每 Cell ≤2 次检索；优先高约束节点与 Seed Spark | 两类信号即可 |
| candidate / shortlist | 每条 **≥2** 个带 URL 的 `fact` 或 `voice`，优先 ≤12 个月 | 加厚替代方案与付费/行为 |
| 失败 | 标缺口，继续碰撞 | 不编造、不拿过期帖充新 |

不对全部 Cell 均摊深搜。中国大陆与海外分列。

## 四类信号

| 信号 | 检索目标 | 常见来源 |
|------|----------|----------|
| 用户说什么 | 抱怨、愿望、放弃原因 | 社群、问答、评论 |
| 用户做什么 | 绕路、土办法 | 教程、Vlog |
| 用户付费买什么 | 装备、课、订阅、人工 | 商品评价、套餐 |
| 为何不满意 | 差评、闲置、换品牌 | 低星评价、对比帖 |

每条记录：`claim`、标签、`source`、`date`、`region`、场景、`confidence`、`反证或缺口`、**来源月份**。

## 从信号到痛痒（段 3）

旅程：`触发 → 准备 → 进行 → 异常/失败 → 收尾 → 复盘/分享 → 维持/放弃`

字段：场景/任务、Pain/Itch、频率、替代方案、不满、**Constraint Lens**、**Unique Friction**、待证伪假设。

优先：已花时间/金钱仍失败或依赖人工。

段 3 给段 4 约束与替代；火花不等待完整证据。晋升后再加厚。无 `fact/voice` 不得 shortlist。
