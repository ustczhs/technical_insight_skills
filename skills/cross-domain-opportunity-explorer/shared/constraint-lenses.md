# 约束透镜（Constraint Lens）

火花碰撞的**发散侧**。透镜描述场景里的物理/认知/社交约束，不是已验证需求。完整清单可扩展；每 Cell 至少选 **2** 个透镜碰撞。

## 透镜表

| 透镜 | 问什么 | 典型场景 | 易出形态 |
|------|--------|----------|----------|
| **双手占用** | 关键时刻能否腾出手操作设备？ | 钓鱼扬竿、骑行控把、厨房烹饪、抱娃、手术级精细活 | 头戴/语音/穿戴拍摄、脚踏/咬合触发、空间固定机位 |
| **瞬间不可错过** | 机会窗口是否只有几秒？ | 上鱼、进球、婴儿第一次、宠物搞怪、路遇 | 预录缓冲、AI 片段截取、声纹/动作触发 |
| **视线被占** | 眼睛是否必须盯目标，不能看屏？ | 路亚盯线、台球走位、滑雪下坡、驾驶 | 语音 UI、抬头显示、骨传导、侧向 HUD |
| **恶劣环境** | 水/尘/汗/噪音/温度/震动？ | 户外、工厂、厨房、泳池、工地 | 防水等级、降噪麦、手套模式、工业外壳 |
| **长时间等待/无聊** | 是否有大块空闲需打发或监测？ | 钓鱼蹲守、通勤、陪护、排队 | 环境感知 Agent、轻娱乐、异常提醒、陪伴对话 |
| **社交展示/内容生产** | 是否要强分享、晒成绩、装备文化？ | 健身打卡、旅行 vlog、盘串包浆、球类高光 | 一键成片、水印/成绩 overlay、社群模板 |
| **教学/陪练/纠错** | 是否需要实时指导或动作纠正？ | 健身、台球、唱歌、乐器、挥杆 | 视觉/IMU 姿态、语音教练、空间投影 |
| **隐私/敏感** | 是否涉及他人、卧室、医疗外观？ | 助眠、居家监控、更衣室、儿童 | 本地推理、物理开关、指示灯、数据最小化 |
| **免提/连续操作** | 是否需连续动作不能中断？ | 骑行导航、跑步、工厂流水线 | 耳戴、指环、胸扣、腰带 |
| **身份/仪式/审美** | 是否重装备美感、仪式感、圈层符号？ | 盘串、Hi-Fi、机械表、露营美学 | 可穿搭硬件、联名、材质/灯效、陈列空间 |
| **协作/多人** | 是否多人同步信息或分工？ | 球类、自驾、家庭照护、乐队 | 空间音频、多设备同步、共享白板/空间 |
| **位置/空间绑定** | 是否强依赖特定地点或动线？ | 健身房、KTV、钓点、球房 | 空间设备、Beacon、门店服务、固定安装 |

## 使用规则

1. **从旅程节点选约束**，不从品类反推人群。
2. **一透镜可多形态**：例如「双手占用 × 瞬间不可错过」→ 预录眼镜、竿夹相机、语音标记。
3. **跨域迁移允许**：滑雪头盔相机逻辑可迁移到钓鱼 — 须在 Spark 标注「跨域灵感来源」。
4. **透镜不代替证据**：碰撞产出默认 `hypothesis`；晋升须补 ≤12 个月行为/替代方案。
5. 每条火花写 Unique Friction；套话杀伤无效。

## 钓鱼示例（完整碰撞链）

```text
Cell: 休闲路亚 × 城郊夜钓 × 留下上鱼瞬间

旅程节点: 进行（扬竿/控鱼/抄网）

透镜:
  - 双手占用（控竿时无法掏手机）
  - 瞬间不可错过（刺鱼到出水仅数秒）
  - 视线被占（需盯线/漂/障碍）

形态碰撞:
  - 智能眼镜 / 头戴：语音或眼动触发，预录缓冲 + AI 高光
  - 竿夹/线组微摄：第一视角，蓝牙连手机
  - 纯软件：事后手动剪 — 杀伤：错过窗口
  - 空间：钓场固定机位 — 杀伤：覆盖有限

→ Spark: 「路亚上鱼瞬间头戴 AI 高光捕获」（hypothesis）
```
