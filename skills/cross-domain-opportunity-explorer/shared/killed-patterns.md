# 已杀模式（Killed Patterns）

碰撞前对照。命中且无**新的 ≤12 个月反证** → 标 `killed` 或并入已有火花，不进 candidate。

| id | 模式 | 为何杀 | 何时可翻案 |
|----|------|--------|------------|
| K01 | 「某兴趣人群需要 AI」无约束 | 无 Unique Friction | 补上具体窗口/姿态 |
| K02 | 手机云台 / 八爪鱼已充分的跟拍 | Citywalk、探店等单手场景通常够用 | 双手占用 + 瞬间窗口同时成立 |
| K03 | 诊断/疗效/医疗器械宣称 | medical-boundary | 仅生活质量/行为支持且转合规 |
| K04 | 纯「大模型聊天陪练」无物理闭环 | AI 可触点为 0 | 有传感器/空间/实时动作闭环 |
| K05 | 头戴 POV 复制粘贴到所有户外运动 | 与 GoPro 胸挂无差异陈述 | 眼平 vs 胸挂的可观察差异 + 付费锚 |
| K06 | 为做硬件而做的「智能手环」空壳 | 手机/手表已覆盖计步类 | 约束使腕表不可用 |
| K07 | 把 TAM/「市场很大」当机会 | 不可证伪 | 换成四杀伤 |
| K08 | 过时评测当现状（>24 个月无标注） | 违反 Recency First | 换新来源或标趋势对照 |
