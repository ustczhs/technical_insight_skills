# 检索范围与 Product Family 解耦

新品类（如摩托车机器人）挂靠 Companion Robot 后，厂商矩阵与探针仍按 Family 偏航，行业优先（摩托车/电动车芯片）无法变成必扫义务。决定：Product Family 只拥有 Dimension Profile；Phase 2 覆盖 = primary Silicon Class ∪ adjacent Classes（含 Hard 触发）∪ Application Domain 加扫；探针按 Silicon Class 门控。暂不引入独立 Retrieval Profile；Out-of-Family 仅表示问卷缺口，不再一刀切降级 Phase 2。
